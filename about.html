The story

From Task 1 to a real site

MainCrafts is the fictional brand I've been building through this Full Stack Web Development internship. Task 1 was a single landing page — hero, features, footer. This task, Task 2, turns it into an actual multi-page site with real navigation between Home, About, and Contact.

The "workshop" idea stuck because it fit the name — measuring twice, building things that are meant to hold up, not just look good in a screenshot. Every page here uses the same shared stylesheet and script file instead of copy-pasted code, the way a real small project would be structured.

Behind the brand: I'm Lakshay, a BTech Computer Science student, building this project by project as part of the internship curriculum.
